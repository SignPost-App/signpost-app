# SignPost

A community resource map for finding and sharing local services like shelters, food banks, and more.

## Getting Started

```bash
npm install
npm run dev
```

## Environment

Copy `.env.demo` to `.env` to configure the app:

| Variable | Description |
|----------|-------------|
| `VITE_DEMO_MODE` | Set to `true` to enable demo mode (uses sample data instead of a live backend) |

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start the development server |
| `npm run build` | Build for production |
| `npm run preview` | Preview the production build |
